# Donation Box

The **Donation Box** app enables religious organizations (mosques, churches, mandirs, etc.) to collect donations from visitors using a mobile device’s NFC capabilities. Visitors can make quick, secure payments by tapping their credit card against the admin’s device during gatherings.

---

## 📲 Admin Onboarding Flow
1. **Download the App** – Available on iOS App Store and Google Play Store.  
2. **Sign In** – Log in using Google, Apple, or email.  
3. **Set Up Organization Profile**:
   - Organization name and logo  
   - Suggested donation amounts (e.g., $5, $10, $50, $100)  
   - Organization description  
4. **Ready for Donations** – Admin can switch the app into **Donation Mode** during events.  

---

## 🙌 Donation Flow (Visitor Experience)
1. **Donation Mode Screen** – Displays organization logo, description, and donation amount tiles.  
2. **Choose an Amount** – Visitor taps a donation tile.  
3. **Payment via NFC** – Visitor taps their credit card against the admin’s device.  
4. **Confirmation Screen** – Displays a receipt and a QR code.  
   - QR code links to signup/donor registration (optional).  
5. **Pass the Device** – Visitor hands the device to the next person.  

---

## ✨ Key Features
- **Instant Setup** – Admin can start collecting donations within minutes.  
- **Multiple Donation Amounts** – Configurable to match event needs.  
- **Quick Payment** – Tap-to-pay via NFC for minimal friction.  
- **Digital Receipts** – Optional email or QR-based proof of donation.  
- **Offline Capability** – Queue transactions when network is unavailable.  

---

## 🔒 Security & Compliance
- Integrates with certified payment processors supporting:  
  - Tap to Pay on iPhone  
  - Tap to Phone on Android  
- No card information stored on the device.  
- PCI DSS compliant.
